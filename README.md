Open Source
-----------

### Exporters and Interoperability
* [OpenGLB](https://quantumnovice.github.io/OpenGLB/) - Open-source Revit to GLB (glTF 2.0 binary) exporter with geometry, hierarchy, materials, and BIM metadata JSON. Revit 2020-2026. (GPL-3.0)
* [Autodesk/revit-ifc](https://github.com/Autodesk/revit-ifc) - Official IFC import/export for Revit (2019+). (Autodesk)
* [EverseDevelopment/revit-glTF-exporter](https://github.com/EverseDevelopment/revit-glTF-exporter) - Revit add-in that exports glTF files. (MIT)
* [mcneel/rhino.inside-revit](https://github.com/mcneel/rhino.inside-revit) - Run Rhino and Grasshopper inside Revit. (MIT)
* [bimone/addins-excelexporterimporter](https://github.com/bimone/addins-excelexporterimporter) - Import and export Revit data through Excel. (MIT)
* [bimone/addins-NWCBatchExport](https://github.com/bimone/addins-NWCBatchExport) - Batch export of Navisworks NWC files. (MIT)

### Productivity and Automation
* [pyrevitlabs/pyRevit](https://github.com/pyrevitlabs/pyRevit) - Rapid application development environment for Revit. Build tools in Python (IronPython or CPython). (GPL-3.0)
* [DynamoDS/DynamoRevit](https://github.com/DynamoDS/DynamoRevit) - Dynamo libraries for Revit. (Apache-2.0)
* [DerekEubanks/Revit-Addin-Full-FU-Flow-Range-Plumbing-Fixture-Flow-Server](https://github.com/DerekEubanks/Revit-Addin-Full-FU-Flow-Range-Plumbing-Fixture-Flow-Server) - Plumbing fixture flow overrides for fixture unit values below 5. (MIT)
* [mattmas/AreaPlanHelper](https://github.com/mattmas/AreaPlanHelper) - Create areas from rooms using BOMA or similar rules. (no license listed)
* [HP-Enterprise/RevitHP](https://github.com/HP-Enterprise/RevitHP) - Family library browser. (no license listed)
* [PitPaf/LazyDetailComponent](https://github.com/PitPaf/LazyDetailComponent) - Detail component helper. (MIT)
* [ricaun-io/RevitAddin.FamilyLoader](https://github.com/ricaun-io/RevitAddin.FamilyLoader) - Load and place Revit families from a plugin. (MIT)
* [ricaun-io/RevitAddin.CommandLoader](https://github.com/ricaun-io/RevitAddin.CommandLoader) - Compile and add IExternalCommand buttons to the ribbon with Revit open. (MIT)
* [khilller/AIrender-revitaddin](https://github.com/khilller/AIrender-revitaddin) - Render images from Revit using Stable Diffusion models. (MIT)
* [EverseDevelopment/ZoidbergAI.Addin](https://github.com/EverseDevelopment/ZoidbergAI.Addin) - AI BIM assistant add-in. (MIT)

### Inspection and Database Tools
* [lookup-foundation/RevitLookup](https://github.com/lookup-foundation/RevitLookup) - Interactive Revit database explorer for inspecting elements and parameters. (MIT)
* [ricaun-io/RevitAddin.UpdaterTester](https://github.com/ricaun-io/RevitAddin.UpdaterTester) - Show which BuiltInParameters trigger an IUpdater. (MIT)
* [TripleZeroLabs/OpenDefinery-RevitAddins](https://github.com/TripleZeroLabs/OpenDefinery-RevitAddins) - Cloud-based shared parameter management. (GPL-3.0)

### Visual Programming
* [DynamoDS/Dynamo](https://github.com/DynamoDS/Dynamo) - Open-source graphical programming for computational design and automation. Runs standalone or inside Revit. (Apache-2.0)

### Developer Tools and Templates
* [Nice3point/RevitTemplates](https://github.com/Nice3point/RevitTemplates) - Project templates for Revit add-ins. (MIT)
* [Nice3point/RevitToolkit](https://github.com/Nice3point/RevitToolkit) - Toolkit for Revit plugin development. (MIT)
* [jeremytammik/VisualStudioRevitAddinWizard](https://github.com/jeremytammik/VisualStudioRevitAddinWizard) - Visual Studio templates for C# and VB.NET Revit add-ins. (MIT)
* [salaros/vs-templates-revit-addin](https://github.com/salaros/vs-templates-revit-addin) - Visual Studio C# template for Revit add-ins. (MIT)
* [romangolev/RevitAddinTemplate.Multiversion](https://github.com/romangolev/RevitAddinTemplate.Multiversion) - .NET project template for multi-version Revit add-ins.
* [ricaun-io/ricaun.RevitTest](https://github.com/ricaun-io/ricaun.RevitTest) - Multi-version NUnit testing framework for the Revit API. (MIT)
* [ricaun-io/ricaun.Revit.UI](https://github.com/ricaun-io/ricaun.Revit.UI) - Revit UI API extension with RibbonItem utilities. (MIT)
* [ricaun-io/RevitAddin.VisualStudioDebug](https://github.com/ricaun-io/RevitAddin.VisualStudioDebug) - Debug add-ins with Visual Studio attached to Revit. (MIT)
* [ricaun-io/RevitAddin.WpfUi.Sample](https://github.com/ricaun-io/RevitAddin.WpfUi.Sample) - WPF-UI sample for the Revit API. (MIT)
* [ricaun-io/RevitAddin.ProgressBar.Example](https://github.com/ricaun-io/RevitAddin.ProgressBar.Example) - Progress bar in a Revit plugin. (MIT)
* [chuongmep/RevitAddinMsiBuilder](https://github.com/chuongmep/RevitAddinMsiBuilder) - Build MSI installers for add-ins from the CLI. (MIT)

### Sample Code and Learning
* [DynamoDS/DynamoRevit](https://github.com/DynamoDS/DynamoRevit) - Reference for Dynamo's Revit integration. (Apache-2.0)
* [songjiahong/revitapisamples](https://github.com/songjiahong/revitapisamples) - Revit add-in samples using the Revit API. (MIT)
* [StarkBIM/SampleRevitAddin](https://github.com/StarkBIM/SampleRevitAddin) - Multi-layer add-in demonstrating dependency injection and unit testing. (MIT)
* [Ibrahim5aad/revit-addin-clean-architecture](https://github.com/Ibrahim5aad/revit-addin-clean-architecture) - Layered clean architecture with MVVM and IoC for add-ins. (no license listed)
* [ADN-DevTech/revit-automation-dwg-exporter](https://github.com/ADN-DevTech/revit-automation-dwg-exporter) - Export views to DWG with Design Automation for Revit. (MIT)
* [BIMCoderLiang/RevitJumper](https://github.com/BIMCoderLiang/RevitJumper) - Search Revit API docs from inside Revit. (MIT)

Paid
----

Prices change often. Check each vendor's listing before buying.

### Autodesk App Store
* [Autodesk App Store for Revit](https://apps.autodesk.com/RVT/en/Home) - Official marketplace for Revit add-ins, both free and paid.
* [SmartHanger](https://apps.autodesk.com/RVT/en/Home) - Manage hangers and supports for MEP curve elements.
* [BIMF Tools](https://apps.autodesk.com/RVT/en/Home) - Includes pipe penetration insertion.

### Commercial Add-in Suites
* [Ideate Software](https://ideatesoftware.com/popular-autodesk-revit-addins) - Autodesk Authorized Developer with several Revit add-ins sold as a bundle.
* [Revizto](https://revizto.com/en/revit-addins-addons-plugins) - Collaboration and issue-tracking platform with a Revit add-in.
* [Graitec](https://graitec.com/uk/blog/free-vs-paid-revit-plugins-comparison-for-2025/) - Vendor of Revit add-in suites. Also publishes a free vs paid comparison.
