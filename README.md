Awesome Revit Plugins [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
=============================================================

> A curated list of plugins, add-ins, extensions, and developer tools for Autodesk Revit, split into open-source and paid.

Awesome Revit Plugins is a curated list of free and commercial add-ins, plugins, and developer tools for Autodesk Revit, for BIM and AEC teams and developers.

Open Source
-----------

### Exporters and Interoperability
* [addins-excelexporterimporter](https://github.com/bimone/addins-excelexporterimporter) - Import and export Revit data through Excel.
* [addins-NWCBatchExport](https://github.com/bimone/addins-NWCBatchExport) - Batch export of Navisworks NWC files.
* [bSDD-Revit-plugin](https://github.com/buildingsmart-community/bSDD-Revit-plugin) - Revit plugin for buildingSMART Data Dictionary (bSDD) classification.
* [CustomExporterAdnMeshJson](https://github.com/jeremytammik/CustomExporterAdnMeshJson) - Custom Revit geometry exporter to ADN mesh JSON.
* [MantisShrimp](https://github.com/ksobon/MantisShrimp) - Bridge between Rhino/Grasshopper and Revit/Dynamo.
* [OpenGLB](https://quantumnovice.github.io/OpenGLB/) - Open-source Revit to GLB (glTF 2.0 binary) exporter with geometry, hierarchy, materials, and BIM metadata JSON. Revit 2020-2026.
* [revit-glTF-exporter](https://github.com/EverseDevelopment/revit-glTF-exporter) - Revit add-in that exports glTF files.
* [revit-ifc](https://github.com/Autodesk/revit-ifc) - Official IFC import/export for Revit (2019+).
* [Revit2glTF](https://github.com/McCulloughRT/Revit2glTF) - glTF format exporter for Autodesk Revit.
* [RevitExportGltf](https://github.com/weiyu666/RevitExportGltf) - Export Revit models to glTF with material and texture handling.
* [RevitIfcClassMap](https://github.com/jmirtsch/RevitIfcClassMap) - Mapping of IFC classes to Revit categories for import.
* [rhino.inside-revit](https://github.com/mcneel/rhino.inside-revit) - Run Rhino and Grasshopper inside Revit.
* [threejs-revit-exporter](https://github.com/CodeCavePro/threejs-revit-exporter) - Batch export Revit files to JSON scene format for Three.js.
